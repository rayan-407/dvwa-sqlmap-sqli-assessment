# Assessment Methodology

## 1. Environment Verification

The DVWA environment was verified locally before testing.

## 2. Authentication

An authenticated DVWA session was established for authorized testing.

## 3. Scope Definition

Testing was limited to the SQL Injection module and the `id` parameter.

## 4. Vulnerability Detection

SQLMap was used to validate the presence of SQL Injection in the authorized lab environment.

## 5. Database Enumeration

The assessment identified the authorized application database and reviewed the permitted training table.

## 6. Evidence Collection

Relevant findings were documented while avoiding exposure of active session credentials.

## 7. Cleanup

Temporary testing sessions and sensitive session information were cleared after testing.
