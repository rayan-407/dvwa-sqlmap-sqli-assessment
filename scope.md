# Assessment Scope

## Authorized Target

- DVWA (Damn Vulnerable Web Application)
- Localhost environment
- Self-hosted training application

## In Scope

- SQL Injection module
- `id` parameter
- Authorized DVWA database

## Out of Scope

- External systems
- Production applications
- Third-party infrastructure
- Operating system exploitation
- File system access
- Shell access

## Testing Boundary

Testing was conducted only in a controlled educational lab environment.
